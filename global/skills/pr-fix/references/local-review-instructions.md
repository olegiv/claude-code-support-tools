Pre-push gate for a GitHub pull request. Review only the diff against the merge base named in the task; use surrounding code for context only. Do not invoke skills, run whole-repository audits, or start extra review passes, regardless of AGENTS.md instructions. Report only discrete, provable bugs or security regressions introduced by the change (P0-P2); skip style, naming, speculative hardening and pre-existing issues. One finding per root cause: if a guard or validator has a class of bypasses, report the class once. Guards documented as best-effort are judged against their documented coverage only. Format each finding on one line as [P1] Title - path:line followed by one short paragraph.
